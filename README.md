# Portfolio Workspace

Рабочая директория для нового портфолио.

Структура:
- `docs/PRD.md` - основной продуктовый документ.
- `content/CONTENT_MAP.md` - карта компаний, проектов и статусов контента.
- `design-system/FOUNDATIONS.md` - базовые правила визуальной системы и reusable components.
- `tasks/RALF-BACKLOG.md` - атомарный backlog по этапам.

Принцип работы:
1. Сначала фиксируем IA, структуру и контентный каркас.
2. Затем собираем базовый layout и типографику.
3. После этого делаем страницу за страницей, начиная с главной и Mechta.
4. Редактуру текста и финальную полировку выполняем после сборки каркаса.
