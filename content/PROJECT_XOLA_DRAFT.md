# Project Draft
## Xola

### Summary
Сервис для поиска рецептов, который помогает модифицировать ингредиенты и инструкции с помощью GPT-чатбота. Проект объединял поиск, готовку, AI-слой и digital-branding.

### Problem
Нужно было сделать понятный продукт вокруг рецептов и AI-помощника, где пользователь может не только находить блюда, но и гибко адаптировать процесс готовки под себя.

### Tasks
- анализ конкурентов;
- Job Stories;
- wireframes;
- дизайн интерфейса;
- digital-branding;
- маркетинговые материалы;
- подготовка финальных макетов под разработку.

### Results
- собрал структуру продукта вокруг поиска рецептов и AI-ассистента;
- спроектировал ключевые сценарии поиска, готовки и редактирования рецептов;
- создал branding и визуальную основу продукта;
- довел проект до финальных макетов под handoff.

### Modules

#### Контекст
Клиент пришел с запросом разработать сервис для поиска подходящих рецептов, который также может помогать с модификацией ингредиентов и инструкций с помощью чатбота на базе GPT.

#### Исследование и логика продукта
- начал с анализа конкурентов;
- собрал Job Stories;
- определил необходимый функционал приложения;
- после этого перешел к wireframes для отработки основных сценариев.

#### Основные продуктовые сценарии
- поиск рецептов;
- экран готовки;
- страница рецепта;
- чатбот;
- добавление рецепта;
- настройка;
- этапы готовки.

#### Визуальное направление
- параллельно собирал digital-branding;
- делал концепты лого и маркетинговых материалов;
- после утверждения структуры и концептов перешел к финальной сборке интерфейса.

### Итог
Этот кейс был для меня важен как пересечение продуктового UX и AI-сценариев. Здесь нужно было собрать не просто каталог рецептов, а сервис с более живым и адаптивным поведением.

### Чему я научился
- проектировать продукт вокруг AI-функции, не делая ее отдельной игрушкой;
- связывать сценарии поиска, чтения и действия в один поток;
- удерживать единый стиль между интерфейсом и брендингом.
