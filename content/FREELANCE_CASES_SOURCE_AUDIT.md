## Что удалось достать

Старое Framer-портфолио содержит 4 отдельных кейса:
- `UniqUnits`
- `CheryX`
- `Xola`
- `Vault`

Согласно `sitemap.xml`, это единственные живые страницы проектов:
- `/projects/uniqunits`
- `/projects/cheryx`
- `/projects/xola`
- `/projects/vault`

Через `searchIndex` удалось достать:
- названия кейсов;
- короткие вводные;
- основные этапы работ;
- список экранов и модулей;
- общий контекст задач.

## Ограничение источника

Текстовые данные удалось снять надежно через search index.

Прямые asset URL для всех внутренних изображений Framer сейчас не достались стабильно: домен `helloyerik.framer.website` отвечает нестабильно при повторных запросах из терминала. Поэтому:
- текстовую структуру кейсов уже можно переносить;
- изображения лучше добирать отдельно, либо через стабильный HTML-доступ, либо через ручной экспорт / скриншоты.

## Как переносить в новую структуру

Для каждого кейса логично использовать единый формат:

1. `Summary`
2. `Problem`
3. `Tasks`
4. `Results`
5. `Modules`
6. `Итог`
7. `Чему я научился`

## Case Notes

### UniqUnits

Тип проекта:
- mobile trading app

Что видно из старого кейса:
- анализ конкурентов;
- интервью с опытными трейдерами;
- гипотезы и их корректировка по ходу работы;
- плотный мобильный интерфейс;
- акцент на управлении рукой и скорости действий;
- проектирование состояний: skeleton, placeholder, loading, error, success.

Модули, которые уже просматриваются:
- авторизация;
- главный экран / трейд-лист;
- график;
- поиск;
- добавление инструментов;
- алго-ордер;
- экономический календарь;
- статьи;
- редактирование списка;
- оповещения;
- позиции;
- ордеры;
- история;
- статистика;
- настройки.

### CheryX

Тип проекта:
- fintech / crypto payments

Что видно из старого кейса:
- приложение для оплаты на POS-терминалах криптовалютой;
- хранение криптовалюты;
- вывод в фиат;
- анализ конкурентов;
- брендинг;
- wireframes;
- финальные интерфейсы и маркетинговые материалы.

Модули:
- главная;
- счета;
- лендинг;
- сплеш-экран;
- ввод PIN-кода;
- преимущества;
- реферальная программа;
- платеж.

### Xola

Тип проекта:
- AI recipe assistant / cooking product

Что видно из старого кейса:
- сервис для поиска рецептов;
- модификация ингредиентов и инструкций с помощью GPT-чатбота;
- анализ конкурентов;
- Job Stories;
- wireframes;
- digital branding;
- финальные макеты под разработку.

Модули:
- мобильная версия;
- поиск;
- готовка;
- рецепт;
- чатбот;
- добавление рецепта;
- настройка;
- этапы готовки.

### Vault

Тип проекта:
- utility app

Что видно из старого кейса:
- платная утилита с 4 инструментами;
- VPN;
- ad blocker;
- проверка утечки паролей;
- проверка скорости подключения;
- сначала wireframes на базе user-flow;
- потом logo / concept;
- затем финальные макеты;
- потом App Store assets.

Модули:
- главная;
- лого;
- проверка скорости;
- VPN;
- onboarding;
- блокировщик рекламы;
- проверка утечки паролей.

## Следующие шаги

1. Переписать каждый кейс в новую структуру.
2. Выбрать, какие из них реально нужны в публичной версии нового портфолио.
3. Добрать обложки и скрины отдельно, когда будет стабильный доступ к ассетам.
